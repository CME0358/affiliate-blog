## 記事管理ルール

### フロントマター形式

```yaml
---
title: "記事タイトル"
date: "2026-03-28"
description: "120文字以内の説明文"
category: "ペット"    # ペット / 睡眠 / 健康 / 暮らし
tags: ["タグ1", "タグ2"]
published: false      # 省略時は公開。false で非公開。
---
```

### 記事追加・デプロイフロー

```bash
cd ~/Downloads/affiliate-blog
git add .
git commit -m "コミットメッセージ"
git push
# → Vercelが自動デプロイ（2〜3分）
```
