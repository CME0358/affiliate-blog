## アフィリリンク挿入の手順（健康カテゴリ）

1. `health_articles_cv.csv` にアフィリURLを列追加
   - 列構成例：`slug, title, affiliate_url_1, affiliate_name_1, affiliate_url_2, affiliate_name_2`
2. CSVを共有 → スクリプト生成
3. `replace_affiliate_links.py`（健康カテゴリ版）を実行
4. 動作確認後 `published: false` を一括削除
5. git push → Vercel自動デプロイ
