### 2. Search Console サイトマップエラー解消

**原因：Vercel Deployment Protectionがsitemapをブロックしていた**
- `/sitemap.xml`アクセス時にVercel認証ページにリダイレクトされGooglebotが弾かれていた
- レスポンスに `x-robots-tag: noindex` も含まれていた

**解決手順**
1. Vercel Dashboard → affiliate-blog → Settings → Deployment Protection → **Vercel Authentication をOFF**
2. Search Console → サイトマップ → 削除して再送信
3. sitemap.xml自体は正常（www固定・109URL・XMLクリーン）

**現状**
- sitemap.xml は200で正常取得できることを確認済み
- Search Consoleの表示更新は数時間〜数日待ちで自然に解消される
