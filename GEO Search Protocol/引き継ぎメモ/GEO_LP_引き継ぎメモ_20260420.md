## headline prop（重要）

AiscanLP・AiscanLP_B両方に `headline` propを追加済み。

```tsx
<AiscanLP />                                                        // ルートLP
<AiscanLP headline={{ industry: '美容クリニック' }} />              // 業種のみ
<AiscanLP headline={{ area: '東京', industry: '美容クリニック' }} /> // エリア×業種
<AiscanLP headline={{ area: '香川', industry: '__none__' }} />      // shindan用
```

### h1切り替えパターン（B案）

| パターン | リード文 |
|---|---|
| デフォルト | ChatGPTに尋ねた瞬間、あなたの会社を探す顧客に |
| 業種のみ | ChatGPTに尋ねた瞬間、"おすすめ{業種}"を探す顧客に |
| エリア×業種 | ChatGPTに尋ねた瞬間、「{エリア}」で"おすすめ{業種}"を探す顧客に |
| shindan（__none__） | ChatGPTに尋ねた瞬間、「{エリア}」でおすすめ業者を探す顧客に |
