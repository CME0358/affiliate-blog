## headline prop（重要）

AiscanLP・AiscanLP_B両方に `headline` propを追加済み。

```tsx
<AiscanLP />                                                        // ルートLP
<AiscanLP headline={{ industry: '美容クリニック' }} />              // 業種のみ
<AiscanLP headline={{ area: '東京', industry: '美容クリニック' }} /> // エリア×業種
<AiscanLP headline={{ area: '香川', industry: '__none__' }} />      // shindan用（おすすめのみ表示）
```

### h1切り替えパターン

| パターン | h1表示 |
|---|---|
| デフォルト（A案） | ChatGPTに「おすすめの会社は？」と聞いたとき あなたの会社、出てきますか？ |
| デフォルト（B案） | AI検索で競合は推薦されているのに〜 |
| 業種のみ | AI検索で"おすすめ{業種}"に選ばれない会社を、3ヶ月以内に露出させるGEO対策 |
| エリア×業種 | 「{エリア}」で"おすすめ{業種}"に選ばれない会社を、AI検索で3ヶ月以内に露出させるGEO対策 |
| shindan（__none__） | 「{エリア}」で"おすすめ"に選ばれない会社を、AI検索で3ヶ月以内に露出させるGEO対策 |

### __none__の仕組み

`industry: '__none__'` を渡すとAiscanLP.tsx・AiscanLP_B.tsx両方で業種名を空文字に置換して表示する。generate-pages.jsのshindanスラッグに設定済み。
