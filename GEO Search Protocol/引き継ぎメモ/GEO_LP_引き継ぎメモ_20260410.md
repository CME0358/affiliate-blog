## headline prop（重要・新規追加）

AiscanLP・AiscanLP_B両方に `headline` propを追加済み。ページ種別でh1が切り替わる。

```tsx
// ルートLP（prop不要）
<AiscanLP />

// 業種のみページ
<AiscanLP headline={{ industry: '美容クリニック' }} />

// エリア×業種ページ
<AiscanLP headline={{ area: '東京', industry: '美容クリニック' }} />
```

### h1切り替えパターン

| パターン | h1表示 |
|---|---|
| デフォルト（A案） | ChatGPTに「おすすめの会社は？」と聞いたとき あなたの会社、出てきますか？ |
| デフォルト（B案） | AI検索で競合は推薦されているのに、あなたの会社だけが「存在しない」ことになっていませんか？ |
| 業種のみ | AI検索で"おすすめ{業種}"に選ばれない会社を、3ヶ月以内に露出させるGEO対策 |
| エリア×業種 | 「{エリア}」で"おすすめ{業種}"に選ばれない会社を、AI検索で3ヶ月以内に露出させるGEO対策 |
